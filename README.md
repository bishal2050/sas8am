# Project Overview

This directory contains a small browser automation project focused on testing the login flow of the DemoBlaze website. It appears to be a learning or practice project for Selenium-based UI automation.

## Main File

- `firstday.py` — A Python script that opens the Chrome browser, loads the DemoBlaze homepage, opens the login form, enters the username and password, and clicks the login button.

## Directory Structure

- `.venv` — Local Python virtual environment used to install and manage project dependencies.
- `.idea` — JetBrains IDE configuration files for this project.
- `firstday.py` — The main automation script.

## Project Purpose

This project is designed to automate a simple web login scenario and validate the behavior of a web page through browser interaction. It is not a full application with a backend, database, or user management system.

## Notes

- The project uses Python and Selenium.
- It targets the Chrome browser.
- The script appears to be a demo/test automation example rather than a production-ready application.
- The credentials in the script suggest it was created for test/demo use.
